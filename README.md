# Тетрадь

Cahier de révision du vocabulaire russe pour francophones, installable sur Android et utilisable hors ligne.

Ouvrir la page dans Chrome, puis menu ⋮ › « Installer l'application ».

La progression reste sur le téléphone (stockage du navigateur). Aucune donnée personnelle n'est envoyée.

## Données

Le vocabulaire russe (accents, genres, conjugaisons, déclinaisons) vient de la base d'[OpenRussian.org](https://en.openrussian.org), publiée sous licence [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Les traductions françaises ajoutées dans `core.json` sont publiées sous la même licence.
